本期主题：压缩与解压

自从互联网分享流行以来，“嘲笑新手不会解压”的弹幕和评论似乎从未断绝。其实，这是一种十分正常的现象。

在移动端设备上，压缩包出现的频率极低，且压缩包的操作与文件系统有着密切的关系。对于刚接触电脑的新手来说，文件系统的相关概念本就陌生，更别提压缩、解压这些进阶操作了。

Tip. 给新手的建议：

压缩和解压涉及到许多文件系统的基础知识，例如：

  • 文件路径
  • 文件后缀名
  • 文件资源管理器的基本操作

如果你对上述概念不够了解，建议花十几分钟先熟悉这些基础操作，这将极大地帮助你顺利掌握本文的知识。

什么是压缩？

压缩文件（俗称“压缩包”）简单来说，就是把多个文件或文件夹打包、整合在一起形成的一个单一文件。

  • 压缩：打包整合的过程。
  • 解压：解开包裹，还原文件的过程。

常见的压缩文件格式包括：zip、rar 和 7z。

为什么要用压缩包？

1. 提高传输效率

这是压缩包最主要的用途。

  • 场景：如果你需要发送 20 个分散的文件。
  • 优势：将其打包成一个压缩包，避免了逐个发送的繁琐，接收方也能一次性获取所有内容。

2. 加速大型资源更新

在网络游戏中，你经常看到“正在下载”、“正在解压”的字样。

  • 原因：游戏更新资源可能高达 4GB，内部包含成千上万个零碎小文件。
  • 优势：下载一个完整的压缩包再本地解压，速度远快于通过网络逐个下载几千个小文件，大大缩短了等待时间。

压缩包的“隐藏用途”

这时候可能有小伙伴会问：

“我下载的东西明明只有一个文件（比如一个安装包），为什么还要压缩一下？这不是多此一举吗？”

这体现了压缩包的一个隐藏用途：增加隐蔽性与持久性。

如今，直接上传安装包或特定软件到分享平台难度越来越高，文件极易因审核机制而消失。

  • 套壳保护：把文件压缩，相当于在外面套了一个“袋子”。
  • 加密便捷：压缩包设置密码比直接给单个文件加密要容易得多。

因此，将文件制成压缩包，能在一定程度上增加文件的隐蔽性，让你需要的资源在互联网上“活”得更久一些。

⚠️ 具体操作核心原则：不要直接打开！

在深入操作之前，必须强调最重要的一点：

🚫 压缩包不是文件夹，请不要直接双击打开使用！

  • 双击的作用：仅起到预览作用，让你查看里面有什么。
  • 正确做法：如果需要对文件进行大量操作（如编辑、运行、安装），强烈建议先将压缩包完整解压出来，再对解压后的文件进行操作。

比喻：就像你想使用包里的雨伞，必须先把它从包里拿出来。你不可能在包里直接撑开雨伞使用。

Windows 自带功能（无需安装软件）

目前的 Windows 10 和 Windows 11 系统默认支持处理大部分 .zip 格式文件。

如何解压

  1. 右键单击压缩包文件。
  2. 选择 “全部解压缩”。
  3. 选择解压路径（若不手动选择，默认解压在与压缩包相同的位置）。
  4. 勾选 “完成时显示提取的文件”。
  5. 点击 “提取”。
  6. 系统自动弹出窗口，即可打开使用。

📦 如何制作压缩包(Windows)

选中想要压缩的文件或文件夹：

  • Windows 10：
    右键 -> 发送到 -> 压缩(zipped)文件夹
  • Windows 11：
    右键 -> 压缩到 ZIP 文件

即可生成标准的 .zip 格式压缩包。

🛠️ 第三方软件推荐：7-Zip

Windows 原生支持的格式有限，建议安装一款功能全面的第三方解压软件。

  • 推荐软件：Bandizip 或 7-Zip（任选其一即可）。
  • 优势：支持格式多（RAR, 7Z, TAR等），功能全面，免费开源。

以下以 7-Zip 为例进行讲解。

1. 安装与菜单调用

安装完成后，右键菜单会有所变化：

  • Win 10：右键任意文件/文件夹，直接出现 7-Zip 选项。
  • Win 11：右键后需点击 “显示更多选项”，才能看到 7-Zip。

2. 执行解压操作（推荐方式）

在右键菜单中选择 7-Zip，然后点击：

📁 解压到 “[文件名]"

优点：软件会自动创建一个与压缩包同名的文件夹，将所有文件集中存放。这非常有利于文件的寻找和整理，避免文件散落一地。

3. 快速压缩文件

选中目标文件或文件夹，右键选择 7-Zip：

  • 快速压缩：点击 添加到 “[文件名].zip”。

  • 高级设置：点击 添加到压缩包…，在弹窗中可设置：
    • 压缩格式（7z, zip, rar等）
    • 压缩级别
    • 添加密码

🔐 特殊压缩包的解压方式

1. 带密码的压缩包

  • 现象：解压时弹出输入密码窗口。
  • 解决：查看资源提供者给出的密码，正确输入即可解压。

2. 分卷压缩包

  • 现象：看到类似 file.zip.001, file.zip.002, file.zip.003 的一系列文件。
  • 原因：单个文件过大，不便传输，因此被切割成多个部分。
  • 解决方法：
    1. 确保所有分卷文件都在同一个文件夹内。
    2. 只需右键点击第一个分卷（即 .001 结尾的文件）。
    3. 选择解压。
    4. 软件会自动识别并拼接所有分卷，完成解压。无需对其他分卷进行额外操作。

Android特别篇

相关软件：MT管理器

在Android上解压

操作步骤：

  1. 找到压缩包文件
  2. 长按它
  3. 选择解压到...
  4. 点击确定

在Android上创建压缩包

操作步骤：

  1. 右滑文件进入多选模式
  2. 选择需要压缩的文件
  3. 长按它
  4. 点击压缩
  5. 选择配置后确定

iOS特别篇

相关软件：神奇解压

在iOS上解压

操作步骤：

  1. 分享该压缩包
  2. 选择导入到神奇解压
  3. 确定
  4. 点击该压缩包
  5. 解压到当前文件夹

在iOS上创建压缩包

操作步骤：

  1. 将需要压缩的文件放入一个文件夹
  2. 长按这个文件夹
  3. 点击压缩
  4. 选择配置后确定

🎉 结语

掌握了以上知识，你就再也不必畏惧网络上的各种压缩包了。无论是日常办公还是游戏下载，都能游刃有余。
